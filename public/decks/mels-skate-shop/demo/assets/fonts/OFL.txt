MODIFICATION NOTICE (OFL clause 2)
  Both files are SUBSETS. They are not the upstream releases. Each carries a
  reduced character set only — measured by decoding each file's `cmap` table:

      U+0020–U+007E  minus  U+005C (\), U+005E (^), U+007E (~)
      U+00B7  MIDDLE DOT
      U+2014  EM DASH

  The subsetting was performed upstream of this repository (the files were taken
  from a local build cache, not fetched for this task); this project only
  renamed and copied them. No glyph outline, name-table string or axis was
  altered here. Neither file uses a Reserved Font Name, so no name change is
  required by OFL clause 3.

  The `unicode-range` declared in `../site.css` is exactly the 94 code points
  above, for both faces, so any character outside that set is handed to the
  fallback stack by the browser rather than silently dropped.
